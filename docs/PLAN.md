# Remote — 远程桌面方案共识与施工计划

> 本文档由设计追问（grill）收敛而成，作为后续实现的唯一产品/架构依据。  
> 开发人员：仅你 + AI。探路代码已开工（见仓库 `relay/` / `web/` / `agent/` / `deploy/`）；VPS 与域名后补。  
> 本机工具安装/卸载见 [TOOLCHAIN.md](TOOLCHAIN.md)。

---

## 1. 目标与非目标

### 目标

- 在公司电脑通过 **浏览器**（后期 **Electron 中性工具皮**）控制 **家中 Windows 桌面**。
- 家中 **无公网 IP**：仅 **出站** 连接自有 **国外 VPS** 中继。
- 不需要传文件；剪贴板文字仅 **手动同步且少用**（正式阶段再做）。
- 体验目标：**1080p**（自适应）；媒体 **WebRTC**；**P2P 优先，TURN 兜底**。

### 非目标 / 明确不做（探路及早期正式版）

- 对抗「翻机器」级取证；**不承诺无痕**（公司端仅 **低残留**）。
- 公司侧 VPN；用 mstsc 作为产品路径（仅允许连通性探测）。
- UAC / 安全桌面控制。
- WOL 远程开机。
- 探路阶段：TOTP、Electron 皮、锁屏/开机登录界面、音频、剪贴板、公司网验收。

### 政策风险（需自知）

 circumvention of employer monitoring/network policy may violate company rules.  
 本方案按「个人远控 + 流量像普通 HTTPS 站点」做工程取舍，**不提供反取证能力**。

## 2. 约束与环境

| 项 | 结论 |
|----|------|
| 家中 | Windows 桌面，单屏；长期开机/挂机；无公网 IP；不做 WOL |
| 公司 | 可下载、可复制文字外带、不可随意外传文件；无 IPv6；普通 HTTPS 多可开，网页 IM/部分网盘常拦 |
| HTTPS 是否解密 | **待公司实测**（看证书颁发者）；暂按「分类拦截为主」设计 |
| 地理 | 家与公司均在 **南京**；仅工作日；每天 ≤6h；约 ≤22 天/月 |
| VPS | **国外近距**（港/日/新等）；约 **¥45/月**；选型偏 **流量/少限速** |
| 域名 | **新购中性域名** + Let’s Encrypt（避开 remote/vnc/rdp 等词） |
| 家用 VPN | 同 VPS 可部署 WireGuard，**仅家/手机用**，与远控进程分离 |

## 3. 拓扑与媒体

```
[公司浏览器 / 后期 Electron]
        |  HTTPS 信令 + WebRTC
        v
   [国外 VPS: Go relay + coturn + 门面]
        ^
        |  出站
[家中 C# Agent]
```

- **主路径**：双边出站 → VPS；无公网 IP，不做「媒体直连家公网」。
- **媒体**：**WebRTC**；ICE **P2P 优先**，失败走 **TURN（coturn）**；走 relay 或带宽不足时 **自动降码率**；目标仍按 1080p 冲。
- **信令/房间**：进房 → token 鉴权 → 再建媒体；换编码/SFU 时尽量不推翻房间模型。
- **会话占用**：探路不做；正式版 **忙则拒绝 + 断线超时释放**（不需要「踢人」产品逻辑）。

## 4. 隐蔽与公司端形态

| 档位 | 选择 |
|------|------|
| 隐蔽 | **档 2**：像普通站点/普通工具；弱化远控字样与路径；不对抗翻机器审计 |
| 公司端残留 | **低残留**：便携、免安装、可删目录 + 清站点数据；**不承诺无痕** |
| 入口顺序 | 先 **浏览器** → 后 **Electron 中性工具皮**（笔记/文档类外观） |
| mstsc | 仅探测公司是否放行出站 RDP；**不进正式方案** |

## 5. 鉴权与权限深度

| 阶段 | 鉴权 |
|------|------|
| 探路 | 固定 **token** / 简单配对码 |
| 正式办公可用 | **设备配对 + TOTP** |
| 会话 | 单人使用习惯；正式：**忙拒绝 + 超时释放** |

| 家中 Agent 深度 | 计划 |
|-----------------|------|
| 探路 M3 | 已登录会话内采屏 + 键鼠即可 |
| v0.2 | **锁屏 + 重启后登录界面** 可输密码进入（服务级 Agent） |
| 不做 | UAC/安全桌面 |

## 6. 技术栈（主线①）

| 部件 | 技术 |
|------|------|
| 家中 Agent | **C# (.NET)**，后期服务自启 |
| 中继 | **Go**（房间/鉴权/信令/门面） |
| TURN | **coturn** |
| 网页端 | **TypeScript** |
| 软件皮 | **Electron**（复用 Web 前端） |
| 仓库 | **monorepo** |

```text

  relay/      # Go
  web/        # TypeScript
  desktop/    # Electron（后期）
  deploy/     # docker compose、coturn 配置
  docs/       # PLAN.md 等
```

## 7. 里程碑

### 7.1 探路（本机 Docker → 上云；不经公司网）

编码顺序：**中继+coturn → 空壳 Agent 进房 → Web 进房 → 真采屏 → 上云**。

**M0 — 基础设施**

- [ ] `docker compose` 一键起：relay + coturn
- [ ] 本机临时域名或 hosts；能 HTTPS 打开门面页（真域名购入后替换）

**M1 — 房间 + WebRTC 信令**

- [ ] 空壳 Agent 用 token 进房
- [ ] 浏览器用同一 token 进房
- [ ] 双方 WebRTC 连通（测试图案/色块即可）
- [ ] 忙占用：探路不做

**M2 — 键鼠闭环**

- [ ] 浏览器键鼠事件送达 Agent（日志或测试窗口）

**M3 — 真桌面**

- [ ] C# 采屏替换测试图案
- [ ] 键鼠操作真桌面（不含锁屏/登录界面）

**M4 — 上云**

- [ ] 同套部署到国外 VPS
- [ ] 家中 Agent 出站 + 家中浏览器经正式域名验证（仍不经公司网）

### 7.2 正式「办公可用」（探路之后）

- 画质向档 2 / 目标 1080p 自适应
- 配对 + TOTP
- 忙拒绝 + 断线超时
- 音频可开关（默认关）
- 剪贴板：手动「同步一次」文字（默认少用）
- 断线自动重连

### 7.3 v0.2

- Electron 中性工具皮 + 低残留清理选项
- 锁屏 + 开机登录界面可登入
- 家用 WireGuard 部署说明（非公司使用）

### 7.4 更后

- 画质/手感继续抬（编码、带宽自适应；必要时再引入更重 SFU）
- 多屏切换（当前单屏）
- 公司网验收；视情况调整域名/门面
